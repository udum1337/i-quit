# Прототип «Не курю»

HTML/CSS/JS-версия приложения. Сначала на прототипе проверялись экраны и логика, потом всё переехало в SwiftUI. Данные демонстрационные, но сценарии настоящие: онбординг, срыв, смена валюты, экспорт.

## Открыть

Онлайн: https://udum1337.github.io/i-quit/prototype/

Локально: `prototype/index.html` или сервер из папки `prototype`:

```powershell
python -m http.server 8000
```

и `http://localhost:8000`.

На iPhone страницу можно добавить на домашний экран. Откроется на весь экран, без адресной строки. После первого запуска работает офлайн. В обычной вкладке остаётся рамка iPhone; полноэкранную вёрстку можно посмотреть с `?standalone=1`.

## Что посмотреть

- Онбординг: 5 шагов, 5 продуктов, 9 валют.
- Главная: стрик, следующая веха, эффект на организм, экономия.
- Таймлайн: 16 вех, у каждой ссылка на источник.
- Прогресс: тепловая карта, график, 17 достижений.
- Настройки: план, валюта, тема, язык, экспорт JSON, сброс.
- Срыв: текущий стрик обнуляется, лучший остаётся. Отмена есть в тосте.

RU/EN и тема переключаются в шапке. Язык и тема сохраняются в localStorage. Остальное живёт в памяти страницы и возвращается кнопкой «Сброс демо».

## Демо-данные

12 дней без никотина, сигареты, 20 в день, пачка за 250 ₽. Это около 3 047 ₽ экономии. «Сброс демо» возвращает те же цифры.

## Ограничения

Прототип не медицинское изделие. Тексты о здоровье собраны по WHO, CDC, NHS, American Cancer Society, American Lung Association, Cleveland Clinic и MedlinePlus; ссылки есть у каждой вехи.

Уведомления здесь не работают, есть только переключатель. Виджетов нет. Сеть не используется, аккаунтов и аналитики тоже нет. Валюта меняет только отображение, курс не применяется.

## Файлы

`js/data.js` — продукты, валюты, вехи, достижения и источники. `js/i18n.js` — строки RU/EN. Экраны лежат в `js/ui-*.js`. `sw.js` кэширует файлы для офлайна: после правок поднимайте версию `CACHE`.
